# Nordlys i natt app: changelog

Versions follow `apps/mobile/package.json`; a release is the tag `mobile-v<version>`
(see docs/MOBILE-RELEASE.md).

## 1.0.0 (unreleased)

- First version: the forecast (YES / MAYBE / NO for tonight), the auroral oval map, the
  next nights' chances and all guides, in Norwegian and English.
- Day-before aurora alerts as native notifications (APNs / FCM) for a saved place, with an
  optional "happening now" alert.
- Alert links open the app (App Links / universal links).
- Ads (AdMob) with Google's consent form and Apple's tracking prompt; none on the alert set-up.
