We welcome feedback – whether you found a mistake in a guide, have a question about the forecast or an idea for an improvement.

## Fastest: GitHub

Open an issue on GitHub: [github.com/webmaxru/nordlys-i-natt/issues](https://github.com/webmaxru/nordlys-i-natt/issues). You can report app bugs, suggest corrections to the guides or ask for new topics there. GitHub issues are public, so please don’t post personal information.

## Direct contact

E-mail the editor, Maxim Salnikov, or reach him on [LinkedIn](https://www.linkedin.com/in/webmax/). Norwegian or English is fine.

## Before you write

- **An aurora question?** Check the [FAQ](id:faq) and the [glossary](id:glossary) first.
- **The forecast was wrong?** Read [how the verdict works](id:how-this-site-works) – aurora forecasts are uncertain and clouds can change quickly. Tell us where and when, and we will use it to improve the service.
- **Privacy:** see the [privacy policy](page:privacy) for what we store and how to delete it.

We reply as soon as we can, but this is a small project without round-the-clock support. In an emergency outdoors in Norway, call 112.
